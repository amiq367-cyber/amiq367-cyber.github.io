# Daliny - building footprints (generated)

Slimmed vector tiles (PMTiles, zoom 14, layer `buildings`, attribute `h` = height in metres when known)
generated from the Overture Maps Foundation buildings theme.

Data: (c) OpenStreetMap contributors, (c) Overture Maps Foundation.
The buildings theme includes OpenStreetMap data and is made available under the Open Database License (ODbL 1.0);
